LIVING WORLD - Windows app

INSTALL
1. Install Node.js (the "LTS" button at https://nodejs.org) if you don't have it.
2. Double-click "Build Living World.bat". The first time it downloads the app
   tools (a few minutes, about 300 MB).
3. A folder opens with "Living World Setup.exe". Double-click it to install.
   You get a Start menu entry and a desktop shortcut.
   Windows may say "Windows protected your PC" because the app isn't signed by a
   company: click "More info" > "Run anyway".

UPDATES
The app checks for updates on its own and asks "Restart now" or "Later".
You don't need to rebuild or reinstall for normal updates.

REMOVING IT
Windows Settings > Apps > Living World > Uninstall.
If "Wipe all my data when Living World is uninstalled" is on (Settings > Data &
privacy in the app), your stories, personas, settings and API key are deleted too.
If it's off, they stay, and reinstalling picks up where you left off.

If you had the older portable "Living World.exe": your data carries over to the
installed app automatically. You can delete the old .exe.
