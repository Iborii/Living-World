LIVING WORLD - Windows app

INSTALL
Download "Living World Setup.exe" from:
  https://github.com/Iborii/Living-World/releases/latest
Double-click it to install. You get a Start menu entry and a desktop shortcut.
Windows may say "Windows protected your PC" because the app isn't signed by a
company: click "More info" > "Run anyway".
You do NOT need Node.js or anything else to install or run the app.

UPDATES
The app checks for updates on its own and asks "Restart now" or "Later".
You never need to rebuild or reinstall for normal updates.

REMOVING IT
Windows Settings > Apps > Living World > Uninstall.
If "Wipe all my data when Living World is uninstalled" is on (Settings > Data &
privacy in the app), your stories, personas, settings and API key are deleted too.
If it's off, they stay, and reinstalling picks up where you left off.

---------------------------------------------------------------------------
FOR DEVELOPERS ONLY (optional)
The installer is built automatically on GitHub. Building it yourself on your own
computer is the only thing that needs Node.js (https://nodejs.org, LTS):
double-click "Build Living World.bat" and the installer appears in "dist".
