# Living World

A roleplay app where every character lives their own story.

## Download
Go to **[Releases](../../releases/latest)** and download **Living World Setup.exe**, then double-click it to install.
Windows may say "Windows protected your PC" because the app isn't signed by a company: click **More info → Run anyway**.

Once installed, the app updates itself.

## What's in here
- `release/`: the update channel the app checks (`latest.json` + `index.html`).
- `desktop/`: the Windows app project. GitHub builds the installer from it automatically.

No API keys, saves, or personal data are stored here; those stay on each computer.
